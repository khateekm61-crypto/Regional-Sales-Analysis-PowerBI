# Regional Sales Analysis & Power BI Dashboard

## Project Overview

This project analyzes historical USA regional sales data to understand revenue, profit, product performance, sales channels, customers, and regional trends.

Python was used for data preparation and Exploratory Data Analysis (EDA), while Power BI was used to build an interactive dashboard for business analysis and reporting.

## Project Objective

The main objectives of this project are to:

- Analyze sales and profit performance
- Identify top-performing products
- Compare sales channels
- Analyze customer revenue and profitability
- Compare sales across U.S. states and regions
- Identify monthly sales trends and seasonal patterns
- Generate business insights and recommendations

## Dataset

The project uses historical sales data from 2014–2018.

The dataset contains multiple tables:

- Sales Orders
- Customers
- Products
- Regions
- State Regions
- 2017 Budgets

## Data Preparation

The data was prepared using Python before analysis.

Key steps included:

- Data loading and initial exploration
- Data cleaning and validation
- Merging multiple tables
- Removing redundant columns
- Standardizing column names
- Creating revenue, cost, profit and profit margin fields
- Creating monthly and geographic fields
- Preparing the final dataset for analysis and visualization

## Exploratory Data Analysis

EDA was performed using Python to understand:

- Monthly sales trends
- Product revenue performance
- Product profit margins
- Sales channel performance
- Average Order Value (AOV)
- Customer revenue
- State and regional performance
- Outliers
- Correlations between numerical variables

## Power BI Dashboard

The interactive Power BI dashboard contains three main pages:

### 1. Executive Overview & Trends
- Total Revenue
- Total Profit
- Profit Margin %
- Total Orders
- Revenue per Order
- Monthly sales trends
- Order value analysis
- Unit Price vs Profit Margin

### 2. Product & Channel Performance
- Top products by revenue
- Product profitability
- Customer revenue and margin analysis
- Sales by channel
- Profit by channel
- Channel margin analysis

### 3. Geographic & Customer Insights
- Top and bottom states
- Top and bottom customers
- Revenue by U.S. region
- Regional profit margin
- Geographic sales analysis

## Key Insights

- Wholesale contributes the largest share of sales.
- Products 26 and 25 are among the leading revenue contributors.
- The West region has the highest sales among the U.S. regions.
- California is the leading state by sales.
- Sales show noticeable monthly and seasonal patterns.
- Revenue is concentrated among a smaller group of high-value customers.
